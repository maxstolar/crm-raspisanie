АВАТАРКИ СПИКЕРОВ
=================

Требования к файлу
------------------
PNG, квадрат 120x120, лицо ближе к верху кадра (CSS обрезает по центру
по горизонтали и от верха). Вес — около 20-25 КБ.

Имя файла — фамилия латиницей, без пробелов, БЕЗ расширения в расписании.
В data.json спикер лежит парой [имя, имя-файла]:

    "sp": [["Петр Ермаков", "ermakov"]]   ->   avatars/ermakov.png

Пока файла нет, на его месте показываются инициалы — страница не ломается.

ВАЖНО: регистр имеет значение. Vasileva.png и vasileva.png — разные файлы.
Имя в data.json должно совпадать с именем файла посимвольно. Для новых
файлов держитесь нижнего регистра.


Как добавить фото — способ 1, из редактора (проще)
--------------------------------------------------
Доступ к репозиторию не нужен.

1. Открыть страницу расписания с #edit в адресе, ввести пароль
2. Кликнуть по дню, вписать имя спикера
3. В поле «Фото спикера» выбрать файл — он сам обрежется в квадрат
   120x120 и уедет в этот каталог
4. Нажать «Применить», затем «Опубликовать»

Имя файла подставится из поля «файл», а если оно пустое — сгенерируется
из фамилии транслитерацией: «Трофим Рудзий» -> rudziy.

Фото уходит в репозиторий сразу при выборе файла, отдельно публиковать
его не нужно. Страница сначала ищет картинку в копии на витрине, а если
там ещё нет — берёт напрямую из GitHub, поэтому только что загруженное
фото видно сразу, не дожидаясь часовой синхронизации.


Как добавить фото — способ 2, вручную
-------------------------------------
Репозиторий -> assets/avatars -> Add file -> Upload files -> перетащить
PNG -> Commit changes. Затем в редакторе вписать имя файла в поле «файл».

При таком способе картинка появится на витрине в течение часа.
