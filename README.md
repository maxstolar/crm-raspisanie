# Расписание школы CRM-маркетологов Mindbox

Одна вертикальная веб-страница + скрытый редактор с паролем.

## Структура репозитория

```
assets/
├── index.html      ← публичная страница (шрифт, лого, вёрстка вшиты)
├── data.json       ← текущий контент расписания (правится через редактор)
└── avatars/        ← фотографии спикеров и workshop.png
```

Всё, что нужно раскатить на прод — содержимое папки `assets/`. Остальные файлы репо (README и т.п.) на прод не идут.

## Как это работает

- Страница при загрузке делает `fetch('data.json')` — использует последнее сохранённое расписание.
- Если `data.json` пустой (`{}`) или не найден — показывается вшитое исходное расписание сент–дек 2026.
- Скрытый редактор открывается по URL с `#edit` и запрашивает пароль (см. `EDIT_PASS` в `index.html`).
- Кнопка «Опубликовать» коммитит `assets/data.json` напрямую в GitHub через API — деплой подхватит и разложит через 1–2 минуты.

## Токен GitHub

Редактор коммитит по fine-grained personal access token с правом `Contents: Read and write` на этот репозиторий. Токен вписан в `index.html` в строку `const GH_TOKEN=...`.

Если токен истёк или потерян — выпустите новый на https://github.com/settings/tokens?type=beta (та же настройка: fine-grained, only this repo, Contents: Read and write, срок — до конца периода использования расписания), и подмените одну строку в `index.html`.

## Пароль редактора

Строка `const EDIT_PASS='...'` в `index.html`. Меняется в одном месте, никаких серверных перезапусков не требуется — просто коммит и подождать деплой.

## Аватарки и визуал воркшопа

Файлы в `assets/avatars/`. Именование см. в `avatars/README.txt`. Для добавления/замены — коммит в репозиторий, редактор их не загружает.

## Домен

Настраивается стандартной DNS-записью на прод-сервер. Со стороны страницы никаких настроек не нужно.
